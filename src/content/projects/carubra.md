CARUBRA adalah platform AI Agent yang mengubah cara perusahaan berinteraksi dengan knowledge base mereka. Dengan integrasi WhatsApp, tim dapat mengakses informasi dan SOP perusahaan secara instant tanpa perlu membuka aplikasi tambahan.

Platform ini dibangun dengan fokus pada user experience yang sederhana namun powerful, memungkinkan perusahaan untuk men-deploy AI agent mereka dalam hitungan menit.

![CARUBRA AI Agent Technology](/assets/img/portfolio/web/carubra-tech.png)

## One Technology, Many Possibilities

CARUBRA membangun AI Agent untuk bisnis, organisasi, dan profesional — disesuaikan dengan kebutuhan Anda.

![Many Possibilities](/assets/img/portfolio/web/carubra-possibilities.png)

**Untuk Siapa CARUBRA?**

- **Bisnis**: Perusahaan, Brand, UMKM, Startup
- **Organisasi**: Instansi, Komunitas, Lembaga Pendidikan, Layanan Publik
- **Profesional**: Konsultan, Penulis/Author, Dosen/Pengajar, Dokter/Tenaga Ahli, Pakar/Narasumber, Founder/Public Figure

## Fitur Utama

- **WhatsApp Native**: Akses AI Agent langsung dari WhatsApp tanpa install aplikasi
- **Knowledge Base Integration**: Upload dan kelola dokumen perusahaan dengan mudah
- **Contextual AI**: AI yang memahami konteks bisnis dan SOP perusahaan
- **Real-time Response**: Jawaban instant untuk pertanyaan tim
- **Analytics Dashboard**: Monitor penggunaan dan performa AI Agent
- **24/7 Availability**: AI Agent siap bekerja tanpa henti
- **Custom Integration**: Terintegrasi dengan sistem internal, API, CRM, dan database
- **Workflow Automation**: Otomatisasi proses bisnis dan tugas

![CARUBRA Platform](/assets/img/portfolio/web/carubra-landing.png)

## Tech Stack

- Frontend: React + TypeScript
- Backend: Node.js
- AI: Custom LLM Integration
- Messaging: WhatsApp Business API
- Hosting: Cloud Infrastructure
