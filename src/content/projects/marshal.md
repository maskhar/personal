Marshal adalah eksplorasi personal dalam membangun pengalaman web yang ringkas, jelas, dan siap digunakan di berbagai ukuran layar.

Project ini fokus pada implementasi design system yang konsisten dengan component-based architecture, memastikan setiap elemen dapat digunakan kembali dan mudah dimaintain.

## Pendekatan

- **Mobile-First**: Desain dimulai dari layar terkecil untuk memastikan konten inti tetap accessible
- **Component Library**: Membangun library komponen yang reusable dan konsisten
- **Performance Optimization**: Fokus pada loading time dan user experience yang smooth

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Design: Figma
- Build Tools: Modern bundler
